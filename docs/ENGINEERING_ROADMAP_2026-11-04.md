# Evaluación y plan de ingeniería — tsp-backtracking-lab

**Fecha de revisión:** 2026-11-04. **Estado:** propuesta técnica basada en inventario y archivos consultados; no acredita pruebas ejecutadas ni producto comercial.

## Evidencia y contexto

Trabajo académico sobre TSP con backtracking y poda, principalmente documentación y demostración didáctica; coautores Andrés Olguín, Maximiliano Valdés y Enrique Chamy.

## Cambios priorizados

1. Implementar o localizar solver Python ejecutable para respaldar la afirmación de optimización; no confundir visualización docs con algoritmo real.
2. Comparar resultados con tsp-bruteforce-lab usando matrices idénticas, límites de tamaño y ruta de regreso.
3. Registrar nodos explorados, podas, memoria y tiempo, documentando casos donde la poda ayuda o no.

## Criterio de aceptación

Tests comparativos de costo óptimo para instancias pequeñas, benchmark repetible y atribución a los tres autores.

## Protocolo Git y preservación

- Crear ramas temáticas y pull requests con cambios pequeños y pruebas; no publicar ejercicios o trabajos ajenos sin permisos.
- Conservar autoría, fechas, informes originales y licencia aplicable. Un derivado comercial requiere evaluación independiente de titularidad.
- No atribuir a MasterTech SpA automáticamente trabajos académicos previos.
- Documentar comandos ejecutados y resultados reales; no inventar métricas ni despliegues.
